# 영어 그림 풀이 (FOR SPEAKING)

외우지 않고 "그림"으로 이해하는 영어 학습 사이트예요. Part 1 전치사 30개, Part 2~4 동사 30개, 예문 1,550여 개, 페이지마다 음성(한국어+영어 / 영어만)이 들어 있어요.

## GitHub Pages로 올리는 방법

### 방법 A. 명령어 (가장 쉬움)
```bash
cd 이_폴더
git init
git add .
git commit -m "영어 그림 풀이"
git branch -M main
git remote add origin https://github.com/내아이디/저장소이름.git
git push -u origin main
```
그다음 GitHub 저장소 → Settings → Pages → Branch를 `main` / `(root)`로 선택하고 Save. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 열려요.

### 방법 B. 웹에서 끌어다 놓기
GitHub 웹의 "Add file → Upload files"는 한 번에 100개까지만 올릴 수 있어요. 이 폴더는 파일이 128개라서 나눠서 올려야 해요.
1. `index.html`, `style.css`, `app.js`, `data.js`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png`, `.nojekyll`, `README.md` 먼저 올리고 Commit
2. `audio` 폴더 안의 mp3를 60개씩 두 번에 나눠 올리고 Commit (폴더 이름은 `audio` 그대로)
3. Settings → Pages에서 `main` / `(root)` 선택

이미 올려 둔 상태에서 고칠 때는 바뀐 파일만 다시 올리면 돼요. 음성은 그대로예요.

## 사용법
- 목차 버튼은 평소에 화면 위에 하나만 보여요. 누르면 왼쪽에 목차가 나오고, **✕ 목차 숨기기**나 바깥을 누르면 닫혀요.
- 페이지 상단의 **한국어+영어**, **영어만** 버튼으로 재생해요. 문장을 누르면 그 문장부터 재생돼요.
- 아래 플레이어: 이전/다음 문장, 일시정지, **반복 횟수(기본 100회**, 1·2·3·5·10·20·30·50·100·200·300·500회, ∞), 속도(느리게·보통·빠르게, 기본 보통), 전체 반복, **다음 페이지 자동**, **타이머**(15·30·60·90분), 처음부터. 폰에서는 처음에 작게 접혀 있고 **설정 ▴**을 누르면 펼쳐져요.
- 아는 문장은 **다음** 버튼으로 넘기세요. 페이지의 마지막 문장에서 다음을 누르면 다음 페이지로 가요.
- **전체 화면**은 큰 글씨로 지금 문장을 보여 줘요. 화면을 두 번 누르면(클릭하면) 닫혀요.
- 멈춘 곳은 자동으로 저장돼요. 다음에 같은 페이지를 재생하면 멈춘 문장부터 이어져요. 맨 위의 "이어서 듣기"로 마지막으로 듣던 곳에 바로 갈 수 있어요. (저장 위치는 브라우저마다 따로예요.)
- 키보드: 스페이스 = 재생/일시정지, ← → = 이전/다음 문장, Esc = 닫기

## 오프라인·앱처럼 쓰기
- 목차 맨 아래 **음성 전부 오프라인 저장**을 한 번 누르면(약 50MB) 데이터 없이도 들을 수 있어요. https 주소(GitHub Pages)에서만 동작해요.
- 폰 브라우저의 "홈 화면에 추가"로 앱처럼 설치할 수 있어요.

## 백그라운드 재생
화면을 끄거나 다른 앱으로 가도 소리는 계속 나와요. 잠금 화면의 재생/일시정지/이전/다음 버튼도 쓸 수 있어요(Media Session).
